# Mail Manager · 多邮箱管理器 v2.5.0

自托管的多邮箱管理面板：Outlook / Hotmail（OAuth：Graph → IMAP 自动回退）与 Gmail、QQ、163、126、Yahoo、阿里邮箱、2925、自定义 IMAP 混合管理。**本版本起提供免安装便携版**：压缩包内自带 Node.js 运行时与对应平台的原生依赖，解压即用。

## ✨ 主要功能

- **取信回退链**：Outlook `Graph API → IMAP 新 (outlook.live.com) → IMAP 旧 (outlook.office365.com) → 本地缓存`，记住每个账户上次成功的通道；微软轮换的 refresh_token 自动写回
- **多服务商**：Outlook OAuth 与 Gmail / QQ / 163 / 126 / Yahoo / 阿里 / 2925 / 自定义 IMAP 统一收信、缓存、附件下载
- **统一收取引擎（v2.5 新）**：任务 = 账户 + 文件夹，自动去重、固定 4 并发、可单独 / 全部取消，只刷新正在查看的列表；整次收取受 `FETCH_TIMEOUT` 限制，不会无限挂起
- **批量导入 / 导出**（自动识别格式与编码，UTF-16 / GBK 均可）、标签、筛选、批量刷新 Token、数据库备份与恢复
- **代理**：SOCKS5 / HTTP，所有通道（OAuth、Graph、IMAP）都走代理
- **Material You 界面**：动态取色（预设种子色 / 自定义 / 壁纸取色）、亮暗色、可选 Liquid Glass；桌面 Navigation Rail + 移动端底部导航；访问密码

## 🚀 快速开始

**Windows**
1. 解压 zip（右键 →「全部解压缩」），进入 `merged-mail-manager-v2.5.0-win-x64` 文件夹。
2. 双击 `启动.bat`（或 `start.bat`），浏览器会自动打开 http://localhost:3000 。
3. 关闭命令行窗口即停止服务。

**Linux**
```bash
tar -xzf merged-mail-manager-v2.5.0-linux-x64.tar.gz   # ARM64 换成 linux-arm64
cd merged-mail-manager-v2.5.0-linux-x64
./start.sh
```

**macOS**
1. 双击下载的 tar.gz 解压（或 `tar -xzf merged-mail-manager-v2.5.0-macos-arm64.tar.gz`）。
2. 首次运行前解除 Gatekeeper 隔离（自带的 node 未经 Apple 公证）：
   ```bash
   xattr -dr com.apple.quarantine ~/Downloads/merged-mail-manager-v2.5.0-macos-arm64
   ```
3. 双击 `start.command`（或在终端运行 `./start.sh`）。

首次启动会自动从 `.env.example` 生成 `.env`（端口 `PORT`、访问密码 `ACCESS_PASSWORD`、超时等），数据保存在启动脚本旁边的 `data/` 文件夹。

## ⬆️ 升级说明

- 把新版本解压到**新文件夹**，然后把旧目录里的 **`data/` 文件夹和 `.env` 文件**复制过去，再启动；数据库会自动迁移（只增列 / 建索引，不丢数据）。
- 从源码版（`start.bat` / `npm start`）迁移到便携版：把源码目录的 `server/data/outlook.db` 复制为便携版的 `data/outlook.db`；若沿用旧 `.env`，请把其中 `DB_PATH` 改为 `../data/outlook.db`。
- 升级前请先关闭旧版本的命令行窗口（端口被占用时新版本无法启动）。
